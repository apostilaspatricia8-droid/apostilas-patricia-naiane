# Apostilas da Patrícia Naiane

Site inicial responsivo para uma loja de apostilas digitais.

## O que já está incluído
- Página inicial com identidade visual demonstrativa.
- Catálogo de produtos de exemplo.
- Busca e filtro por categoria.
- Layout adaptado para celular.
- Seções sobre a loja e dúvidas frequentes.

## Importante
Esta é uma versão visual inicial. Os produtos, preços e capas são demonstrativos. Não há checkout, pagamento, cadastro de pedidos ou download real de arquivos. Não anuncie os exemplos como produtos disponíveis para compra.

## Como publicar pelo GitHub
1. Crie um repositório chamado `apostilas-patricia-naiane`.
2. Envie `index.html`, `style.css`, `script.js` e este `README.md` para a raiz do repositório.
3. Para publicar sem custo inicial, crie uma conta na Cloudflare e conecte o repositório ao Cloudflare Pages.
4. Escolha o repositório, selecione a implantação de site estático e deixe o comando de build vazio; o diretório de saída é `/` (raiz), conforme a configuração oferecida pela interface.
5. Depois da implantação, teste o endereço em computador e celular.
